================================================================================

Frontend:

  npm install

================================================================================
STEP 2: START DEVELOPMENT SERVERS
================================================================================

Open TWO Terminal Windows:

WINDOW 1 - Backend API Server:
  cd backend
  python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

WINDOW 2 - Frontend UI Server:
  cd frontend
  npm run dev

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "ModuleNotFoundError: No module named 'fastapi'"
Fix: Run: pip install -r requirements.txt

Issue: Backend won't start
Fix: 
  - Check Python version: python --version (needs 3.10+)
  - Check port 8000 is free: netstat -ano | findstr :8000

Issue: Frontend won't start
Fix:
  - Check Node version: node --version (needs 18+)
  - Run: npm install
  - Try different port: npm run dev -- --port 3000

Issue: Can't connect frontend to backend
Fix:
  - Ensure backend is running on http://127.0.0.1:8000
  - Check CORS settings in backend/app/main.py
  - Check browser console for full error

Issue: Database errors
Fix:
  - Delete database/quicktym.db and restart backend
  - This will recreate tables with current schema
