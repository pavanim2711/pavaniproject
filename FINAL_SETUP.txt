INSTALLATION STEPS (COPY & PASTE)
================================================================================

STEP 1: Install Backend Dependencies
================================================================================
cd backend
pip install -r requirements.txt

This installs:
  - FastAPI 0.115.0
  - SQLAlchemy 2.0.31
  - Pydantic 2.10.0
  - All authentication & database libraries


STEP 2: Install Frontend Dependencies
================================================================================
cd ../frontend
npm install

This installs:
  - React 18.3.1
  - Vite 5.4.0
  - PostCSS & Autoprefixer
  - TypeScript & dev tools


STEP 3: Start Backend (Terminal 1)
================================================================================
cd backend
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Expected output:
  INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
  INFO:     Started reloader process


STEP 4: Start Frontend (Terminal 2)
================================================================================
cd frontend
npm run dev

Expected output:
  VITE v5.4.21  ready in XXX ms
  Local:   http://localhost:5173/
  Network: http://XXX.XXX.XXX.XXX:5173/

================================================================================
TROUBLESHOOTING
================================================================================

ERROR: "pip: command not found"
  SOLUTION: Make sure you're in the backend folder and Python is installed
  CHECK: python --version

ERROR: "npm: command not found"
  SOLUTION: Make sure you're in the frontend folder and Node.js is installed
  CHECK: node --version

ERROR: "Port 8000 already in use"
  SOLUTION: Use a different port
  RUN: python -m uvicorn app.main:app --port 8001

ERROR: "[Failed to load PostCSS config]"
  STATUS: FIXED! This should not appear anymore

ERROR: "Cannot find module 'fastapi'"
  SOLUTION: Reinstall backend dependencies
  RUN: pip install -r requirements.txt

ERROR: "npm ERR! ERR code ERESOLVE"
  SOLUTION: Use legacy peer deps (or it may work now)
  RUN: npm install --legacy-peer-deps

ERROR: "Module not found: styled-components"
  SOLUTION: Reinstall frontend dependencies
  RUN: npm install
